# Blink

**[View Live App](https://karim-tari.github.io/blink-prototype/)**

Blink is an AI-powered shopping assistant that lets you buy anything through simple conversation. Instead of browsing endless product pages and comparing prices across multiple sites, just tell Blink what you're looking for and it handles the rest - from product discovery to checkout. Shopping made as simple as having a conversation with a friend.

## Setup

### Environment Variables

1. Create a `.env` file in the project root
2. Add your fal.ai API key:
   ```
   REACT_APP_FAL_KEY=your_fal_ai_api_key_here
   ```
3. Get your API key from [fal.ai dashboard](https://fal.ai/dashboard)

### Installation

```bash
npm install
npm start
```

**Note:** The `.env` file is already in `.gitignore` so your API key won't be committed to GitHub.
